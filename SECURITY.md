# Security

Please don't report security problems in a public issue. Use GitHub's private reporting instead: the repository's **Security** tab, then **Report a vulnerability**. Only the maintainer sees the report.

This includes anything that lets a player:

- get into someone else's account;
- read data they shouldn't;
- crash or take over the game server;
- cheat past the server's authority (moving, looting or fighting in ways the server should refuse).

You'll get an answer as soon as possible. Only the latest beta release gets fixes.
